# 🚀 Kenven Hub

مركز الموارد والشروحات التابع لـ **Kenven Service** - تصميم Neon Dark Cyberpunk Premium.

## 📋 نظرة عامة

Kenven Hub هو موقع محتوى/مدونة متخصص في مشاركة الموارد والشروحات:
- 📱 Apps & Tools - روابط تحميل تطبيقات وأدوات
- 🌐 Websites - مواقع مفيدة وموارد
- 🔓 Activation - طرق تفعيل البرامج
- 🛠️ Fixes & Tutorials - شروحات إصلاح المشاكل
- 💰 Deals & Offers - عروض وخصومات
- 📚 Guides - أدلة شاملة

## 🛠️ التقنيات

- HTML5 + CSS3 + Vanilla JavaScript (بدون Frameworks)
- Firebase (جاهز للتفعيل)
- Font Awesome 6
- Google Fonts (Space Grotesk, Cairo, Orbitron)
- Quill.js (محرر النصوص)
- PWA Ready (قابل للتثبيت)
